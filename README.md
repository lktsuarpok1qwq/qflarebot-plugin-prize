# qflarebot-plugin-prize

QFlareBot 的奖品中心插件，提供积分抽奖、商品库存和人工兑奖，需配合 QFlareBot 宿主及 Points 插件使用。

## 功能

- 多奖池管理，支持积分、虚拟奖品、其他奖品及未中奖
- 独立库存，商品创建后绑定奖池
- 购买直接扣除积分，积分奖励自动入账，商品中奖后进入后台待发放
- 查询抽奖和兑奖记录，后台管理发放、统计及异常恢复
- 自定义机器人回复、按钮与帮助文案，预览和发送共用排版规则

## 启用

1. 在 QFlareBot 中安装 Prize，并启用 Points 的 `points.wallet` 服务。
2. 在 Points 中启用 `prize` 来源，授予 `burn`、`reverseOwn` 操作权限和 `balance` 读取权限。
3. 在 Prize 设置页点击“加载状态”，确认积分接入就绪。
4. 创建奖池并配置奖项；商品奖先创建库存，再绑定奖池，最后手动开放奖池。

数据库与默认配置自动准备。管理页面手动加载数据，切换标签不自动查询。修改 Points 授权前先暂停新购买并处理未完成业务；重新授权后需明确核验或恢复。

## 命令

| 命令 | 用途 |
| --- | --- |
| `/抽奖 [游标]` | 查看开放奖池，省略游标显示首页 |
| `/抽奖 抽 <奖池ID>` | 按当前规则购买一次 |
| `/抽奖 奖项 <奖池ID>` | 查看奖励与中奖概率 |
| `/抽奖 记录 [奖池ID] [游标]` | 查询本人记录，省略奖池 ID 查看全部 |
| `/兑奖 [游标]` | 私聊查询本人已获得的奖品 |

前缀以宿主配置为准。群聊触发兑奖时提示前往私聊；商品中奖无需申请领取或提交资料，由管理员在后台发放。异常资金操作沿原编号恢复，重复事件不会重复扣款。

## 接入

使用 QFlareBot 公开 SDK API_VERSION 4。源码安装由宿主构建，数据使用宿主 D1，R2 用于可选历史归档。
